# 开发者平台与 RuoYi-Plus 对标推进

日期：2026-10-23 至 2026-10-24。基线：d01bbb3。

## 本轮交付

1. Excel 纵向切片：模板、xlsx 预检、逐行错误、确认后原子新增和受数据范围约束的导出。以 demo 为例，新增 V31 权限，复用现有 Excel、保护和隔离机制。
2. 源码驱动的开发者目录：读取 Maven reactor/POM、业务清单、前端清单及自动配置入口，生成可筛选目录和可全文检索的静态索引。声明的功能与扩展点必须有真实源文件和指南；CI 检查快照是否过期。
3. 架构文档：分开编译依赖、运行装配、权限数据链路与扩展协议，准确说明现有实现及限制。更新对标矩阵，区分现成能力、增强点和后续事项。

## 实施边界

- 参考 RuoYi-Vue-Plus 5.X 和 plus-doc 5.X/6.X 的功能分类，不宣称兼容其配置或所有组件。
- Excel 导入仅新增，不按外部 ID 覆盖；预检不写库；服务端提交重新校验并设置可信租户/归属。
- 架构目录展示源码声明，不冒充运行健康检查；requiredModules 有启动校验，requiredStarters 本轮在构建侧核对依赖可达性。
- 文档可离线搜索，不把外部模型服务或 AI 问答当作本轮已交付。
- 保留原有 tsbuildinfo、.serena、根 package-lock；集成使用独立临时 PostgreSQL/Redis。

## 验收

执行聚焦与完整后端测试、前端测试/类型/构建、真实 PostgreSQL 导入与权限测试、浏览器完整链路、文档源码索引契约测试、严格文档构建和根/子路径手机导航验收。完成后记录实际结果。
