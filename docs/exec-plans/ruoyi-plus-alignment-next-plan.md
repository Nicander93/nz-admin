# RuoYi-Vue-Plus 对齐后续计划

## 已完成

- 系统管理：用户、角色、菜单、部门、岗位、字典、参数、公告、日志和在线用户。
- 工程能力：模块协议与注册表、Flyway、独立任务模块、代码生成器、项目 CLI 和 CI。
- 扩展能力：客户端管理、文件配置、可选 Redis 监控、邮件、可删除 demo 模块。
- 基础防护：Sa-Token、数据权限、限流、重复提交、XSS 清理和文件配置密钥加密。
- 多租户闭环：租户与套餐管理、租户登录、MyBatis 行级隔离、套餐权限边界和 V9 迁移。
- 敏感字段保护：AES-GCM 通用 starter、用户联系方式加密、权限驱动脱敏、密钥轮换和 V10 迁移。
- 实时消息：SSE/WebSocket、一次性票据、用户与租户定向推送、连接统计、前端控制台和 V13 迁移。
- 短信管理：可插拔渠道、模板、发送记录、测试发送、前端页面、权限和 V14 迁移。

- 短信验证码登录：验证码生命周期、客户端授权类型、登录页双模式、手机号摘要和 V15 迁移。
- 第三方账号：OAuth2/OIDC、PKCE、一次性 state、登录与绑定、前端回调、菜单权限和 V16 迁移。
- 站内消息中心：租户内逐用户收件箱、未读角标、已读与删除、管理员发送、实时通知和 V17 迁移。
- 个人中心：当前用户资料、角色岗位、联系方式唯一性、密码修改、受保护头像和 V18 迁移。
- 工作流基础：独立 `nz-workflow` 模块、租户流程分类树、分类约束、前端页面、权限和 V19 迁移。
- 工作流定义：版本链、模型连通性校验、复制、发布/取消发布、激活/挂起、JSON 导入导出、前端页面和 V20 迁移。
- 流程实例：定义与变量快照、顺序流和条件互斥分支、办理人校验、同意/驳回/撤回/终止/启停、运行轨迹、前端页面和 V21 迁移。
- 流程任务：独立当前/历史/抄送表、存量待办回填、我的待办/已办/抄送、任务办理、转办、抄送已读、前端页面和 V22 迁移。
- 任务委派：保留原办理人、受托人完成后归还、禁止受托人直接推进流程、前端操作、权限和 V23 迁移。
- 交付环境：PostgreSQL、可选 Redis/MinIO、前后端镜像、健康检查、持久卷、一键 CLI 和部署验收文档。
