## 我们选择沉淀的特色

- **可装配模块**：业务自动配置按开关扫描；前后端清单衔接动态菜单。关闭模块不删除业务数据。
- **权限落到记录**：功能权限、租户和数据范围分别校验，导入归属与导出范围延续同一边界。
- **业务与流程通过协议协作**：官方经典画布负责设计；业务 SPI、快照和事务事件负责单据一致性。
- **文档能回到源码**：目录从 POM、清单和公开接口生成；变更超出架构边界或忘记更新索引时，构建明确失败。
- **验证区分层次**：单测、数据库、浏览器与双节点验收各自证明对应行为，不用构建成功替代完整操作。

这些能力以当前实现为准。动态数据源、通用低代码表单、分布式调度和 AI 问答仍需独立设计与验收，不作为已交付功能宣传。

第一次接触项目，可以按[环境准备](/start/environment) → [首次登录](/start/first-login) → [架构全景](/developer/architecture)阅读。已有目标时，直接搜索类名、模块名或业务词，例如 TenantTableRuleCustomizer、nz-workflow、数据范围。

本站支持本地全文搜索和离线静态部署。可交互目录展示源码声明，线上实际启用状态要在对应应用进程与配置中确认。
