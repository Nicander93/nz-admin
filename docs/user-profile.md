# 个人中心

个人中心对齐 RuoYi-Vue-Plus 的当前用户资料能力。登录用户可以查看自己的角色和岗位、修改昵称与联系方式、设置性别、更换头像和修改密码。

## 接口与权限边界

- `GET /api/system/profile`：读取当前用户资料、角色组和岗位组。
- `PUT /api/system/profile`：修改当前用户昵称、邮箱、手机号和性别。
- `PUT /api/system/profile/password`：校验旧密码后修改密码。
- `POST /api/system/profile/avatar`：上传并替换当前用户头像。
- `GET /api/system/profile/avatar`：以当前登录令牌读取受保护头像文件。

个人中心不使用管理员菜单权限。所有接口都从服务端登录会话取得用户 ID，前端不能提交目标用户 ID；因此普通登录用户只能修改自己。页面通过顶部用户菜单的“个人中心”进入，静态路由仍受全局登录守卫保护。

管理员维护其他用户继续使用 `system:user:*` 权限，两种入口不会共用目标用户参数。

## 数据和安全

V18 为 `sys_user` 增加：

- `gender`：`0` 男、`1` 女、`2` 未设置。
- `avatar_file_id`：指向文件管理记录的逻辑引用。

邮箱和手机号继续经过字段加密处理，修改前会在当前租户内检查重复。密码使用 BCrypt 校验和重建摘要，旧密码错误或新旧密码相同时拒绝修改。

头像复用 `nz-starter-file` 的扩展名、MIME、大小和路径安全校验，并额外要求 MIME 为图片。头像文件不会变成匿名公开资源，前端通过携带登录令牌的 Blob 请求加载；替换成功后会清理旧头像，数据库更新失败时会回收新文件。

## 迁移

- Flyway：`V18__user_profile.sql`
- 人工升级：`db/upgrade-p18-user-profile.sql`

个人中心没有新增菜单或按钮权限数据，这是刻意的权限设计：如果把它绑定到管理员菜单，未分配系统管理权限的普通用户将无法维护自己的账号。
